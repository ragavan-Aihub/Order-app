How to read the privacy policy draft
=====================================

Privacy-Policy-For-Review.pdf
  Open with macOS Preview (double-click), Adobe Reader, or send via WhatsApp.
  Do NOT open inside Cursor/VS Code — the editor shows binary gibberish.

Privacy-Policy-For-Review.html
  Double-click to open in Safari/Chrome. Print → Save as PDF if needed.

Privacy-Policy-For-Review.txt
  Plain text — easy to read in any app or paste into chat.

Regenerate all three from repo root:
  npm run docs:privacy-pdf
